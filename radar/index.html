    最近一次周报精选¶

    生成时间：2026-10-19T09:22:26Z。以下是该任务实际输出并保存的筛选结果：

    • RPD + SARA — 文档理解；筛选日期：2026-10-19

      • 研究摘要：结构感知的统一文档解析方法，目标是更好保留文档布局和结构信息。已存档周报报告了 layout F1 为 0.9189、对比 LoRA baseline 的 0.7004；该数值应结合原论文的实验设置核验。

      • ChatGPT 入选理由：原周报列为 A 优先级；模型权重和数据被记录为开放，且提供了 GitHub 与 Hugging Face 入口，适合作为文档解析的复现基线。

      • 后续研究机会：在跨版式、长文档、表格混排和扫描质量变化条件下复现布局指标；比较量化推理、LoRA 微调与结构约束对精度和显存的影响。

      • GPU 需求：T4 量化推理可行；LoRA 约需 24GB；全量训练至少约 40GB（按已存档周报记录，需实测复核）

      • 参数规模：2B

      • 资源：论文 · GitHub · Hugging Face

    • semCER — 文档理解；筛选日期：2026-10-19

      • 研究摘要：面向 OCR 的语义严重度加权评测思路，试图区分对含义影响不同的识别错误，而不只把所有字符编辑视为等价。

      • ChatGPT 入选理由：已存档周报记录了 T4 16GB 环境测试，并报告 FP32 约 46 edits/s；完整蒸馏流程尚未确认，适合开展可复现实验和评测方法研究。

      • 后续研究机会：检验语义严重度指标与下游信息抽取、文档问答质量之间的相关性，并在多语言、表格和票据 OCR 场景中进行对照。

      • GPU 需求：已存档周报记录 T4 16GB 可运行；约 46 edits/s 为 FP32 报告值，需按原设置复核

      • 参数规模：0.8B

      • 资源：论文 · GitHub · Hugging Face

    • Intern-Decision — 多模态小模型；筛选日期：2026-10-19

      • 研究摘要：面向结构化决策输出的小模型系列，强调一次生成结构化决策结果。

      • ChatGPT 入选理由：已存档周报记录训练代码开放，并覆盖多个参数规模，适合在统一任务和资源预算下比较模型规模、结构约束与泛化能力。

      • 后续研究机会：设计未见过的字段 schema、长尾类别和格式扰动测试；比较不同规模模型的结构有效率、任务准确率和推理成本。

      • GPU 需求：0.8B/2B 推理可尝试 T4；4B 约需 24GB 显存（按已存档周报记录）

      • 参数规模：0.8B / 2B / 4B

      • 资源：论文 · GitHub

    • MaLoW — 视频理解；筛选日期：2026-10-19

      • 研究摘要：面向视频理解的参数记忆与动态 LoRA 方向，探索如何在有限模型容量下保留和调用视频上下文信息。

      • ChatGPT 入选理由：覆盖较小模型规模，适合研究长视频记忆、参数效率和视频 token 预算之间的关系；已存档周报指出训练代码与数据开放状态仍需核验。

      • 后续研究机会：在固定显存和长视频输入条件下，比较记忆模块、帧采样和 token 预算对 VideoQA、时间定位与长程信息召回的影响。

      • GPU 需求：0.8B/2B 可尝试 T4 推理；4B 约需 24GB 显存（按已存档周报记录）

      • 参数规模：0.8B–9B

      • 资源：论文 · GitHub · Hugging Face

    • VideoJev — 视频理解；筛选日期：2026-10-19

      • 研究摘要：面向视频的直接候选评分与缓存思路，尝试减少视频理解中重复或低价值计算。

      • ChatGPT 入选理由：提供了论文和 GitHub 项目入口，适合评估直接视频决策与候选缓存的计算收益；T4 可运行性尚未确认。

      • 后续研究机会：在固定视频长度、采样策略和显存预算下比较准确率、吞吐、延迟与缓存命中率，并检查训练流程的可复现性。

      • GPU 需求：建议约 24GB 显存；T4 未验证；全量训练据已存档周报记录需要多 GPU

      • 参数规模：4B

      • 资源：论文 · GitHub
