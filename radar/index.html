    2026年第43周通过复核主题匹配度 ≥8.0
    综合评分7.75/10

    TrajTok: Learning Trajectory Tokens enables better Video Understanding

    TrajTok提出与视频模型联合训练的轨迹式视觉tokenizer，不依赖额外的精细跟踪前处理，并展示其作为视频编码器、适配器及VLM连接模块的多种用法。原论文及Apple研究页说明它试图在长视频推理中降低视觉token冗余。

    创新性
    8.5/10
    开源完整度
    7.5/10
    复现可行性
    6.5/10
    科研潜力
    8.5/10

    研究价值

    该方法针对长视频token数量随时长增长的算力瓶颈，具有方法创新性；可找到对应论文、公开代码及部分权重入口，且研究问题能够设计对照实验。当前尚未在本项目中独立复现实验，GPU配置仍需核实。

    学生切入点

    以统一视频数据和固定GPU预算比较轨迹token、均匀patch压缩及帧采样方法，评估时间定位、VideoQA正确率、token数、吞吐和显存，并分析短时局部运动与长时关系的泛化边界。

    文档理解

    RPD + SARA

    结构感知的统一文档解析方法，目标是更好保留文档布局和结构信息。已存档周报报告了 layout F1 为 0.9189、对比 LoRA baseline 的 0.7004；该数值应结合原论文的实验设置核验。

    价值点原周报列为 A 优先级；模型权重和数据被记录为开放，且提供了 GitHub 与 Hugging Face 入口，适合作为文档解析的复现基线。

    学生切入在跨版式、长文档、表格混排和扫描质量变化条件下复现布局指标；比较量化推理、LoRA 微调与结构约束对精度和显存的影响。

    参数量：2B
    GPU需求：T4 量化推理可行；LoRA 约需 24GB；全量训练至少约 40GB（按，需实测复核）
