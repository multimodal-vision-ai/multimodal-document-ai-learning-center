# 常见问题 / FAQ

## 我没有独立 GPU，能完成课程吗？

可以。Week 1–7 可在 CPU 环境完成；Week 8–10 使用 Kaggle/Colab 免费额度、小模型、小数据集或更短训练。评价重点是实验设计、可复现证据与结果解释，不是模型规模。

## 训练失败或指标没有提升，会扣分吗？

不会因“负结果”本身扣分。保留配置、日志、失败原因、排查过程和下一步假设，仍可获得验证与分析分。隐藏失败、挑选性汇报才会影响评分。

## 可以使用 ChatGPT、Copilot 或其他 AI 编程工具吗？

可以，而且 Week 3 明确要求使用。你必须披露使用范围，保留关键交互摘要，并用测试、官方文档和人工审查验证输出。最终代码必须能由你本人解释。

## W&B API key 放在哪里？

使用环境变量、W&B 登录命令或平台 Secret 管理，不要写进 notebook、配置、截图或 Git 历史。若意外提交，应立即撤销并轮换 key。

## W&B 项目必须公开吗？

不必须。私有项目可向导师授权，或提交脱敏的图表、配置 diff、run ID 和 report 导出。不得为了公开作业上传敏感数据。

## 应该选哪个模型？

选择能在现有资源上稳定复现的最小模型。先验证 pipeline 和评测，再扩大规模。模型 card、license、显存需求和任务适配度比参数数量更重要。

## Notebook 在我的电脑能运行，为什么仍不算可复现？

常见原因是依赖未固定、模型 revision 未记录、依赖本地绝对路径、隐藏 cell 状态或数据未说明来源。请从空环境“Restart & Run All”，并让同学按 README 复现一次。

## 链接失效或课程内容过时怎么办？

优先寻找同一项目的官方文档新地址，并提交 issue 或 PR；不要用未经验证的博客替换官方来源。仓库的文档检查会定期暴露失效链接。
