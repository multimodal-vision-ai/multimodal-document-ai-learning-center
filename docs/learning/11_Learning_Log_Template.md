# 自主学习记录模板

复制下面内容到个人仓库的 `learning-log.md`，每周追加一节。记录应简短、具体，并能指向代码、配置、原始输出或实验报告。

```markdown

- 主线项目：__ 小时
- 评测与失败分析：__ 小时
- 自主探索：__ 小时
- 记录与例会准备：__ 小时

### 本周主线成果
- 完成了：
- 尚未完成：
- 最小运行命令：

### 环境与复现信息
- Git commit：
- Python / CUDA / GPU：
- 模型与 revision：
- 数据集与 version / split：
- 随机种子：
- 配置文件：

### 实验记录
| Run | 唯一改动 | 关键配置 | 结果 | 原始证据 |
| --- | --- | --- | --- | --- |
| baseline | — | | | |

### AI 使用披露
- 使用的工具与版本（如可知）：
- AI 完成或建议了什么：
- 我如何核验（测试、文档、人工审查）：
- 我拒绝或修改了哪些建议，为什么：

### 自主探索方向
- 我选择的方向：
- 为什么与当前项目相关：
- 我只改变或验证什么：
- 结果与证据：

### 自主阶段
- [ ] 未形成：只有阅读或尝试
- [ ] 已跑通：最小任务成功
- [ ] 可复现：别人可以重新运行
- [ ] 可解释：能说明证据、失败和限制
- [ ] 可扩展：能提出并验证新问题

### 当前判断

- 一个失败或意外：

### 例会前准备
```

!!! note "Week 9–10"
    另外记录 W&B project、run ID、artifact version 与 report 链接。私有项目可保留脱敏导出，但仍应记录能够核对配置和运行的标识。

!!! tip "记录不是周报"
    不需要复述阅读内容。优先记录做了什么、证据在哪里、为什么这样判断、哪里失败，以及下一步准备验证什么。
