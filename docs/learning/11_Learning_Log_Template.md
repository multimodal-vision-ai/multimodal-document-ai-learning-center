# 学习记录模板 / Learning Log Template

复制下面内容到个人仓库的 `learning-log.md`，每周追加一节。记录要简短、具体、能指向证据。

```markdown
## Week __｜主题

### 本周目标
- 我计划验证：
- 完成标准：

### 环境与复现信息
- Git commit：
- Python / CUDA / GPU：
- 模型与 revision：
- 数据集与 version/split：
- 随机种子：
- 运行命令：

### 实验记录
| Run | 唯一改动 | 关键配置 | 结果 | 证据链接 |
| --- | --- | --- | --- | --- |
| baseline | — | | | |

### AI 使用披露
- 使用的工具与版本（如可知）：
- AI 完成或建议了什么：
- 我如何核验（测试、文档、人工审查）：
- 我拒绝/修改了哪些建议，为什么：

### 结果与反思
- 最重要的发现：
- 一个失败案例：
- 当前限制：
- 下周首先要解决的问题：
```

!!! note "W&B 周次"
    Week 9–10 还需填写 W&B project、run ID、artifact version 与 report 链接；私有项目可提交脱敏导出，但仍应保留可核对的标识。
