本栏目集中展示经过审核的团队自研模型及 Hugging Face Spaces。模型推理、上传和对比界面由各项目的 Space 独立提供，学习中心负责统一介绍与入口。

## 模型展示规范

每个正式项目需要提供：模型名称与版本、研究任务与自研特色、真实效果封面、HF Space 地址、模型与评测资料链接，以及必要的运行限制。

优先提供“在 Hugging Face 打开”链接。需要嵌入时仅按需加载已审核的 Space，并说明第三方算力可能出现排队、休眠或额度限制。
