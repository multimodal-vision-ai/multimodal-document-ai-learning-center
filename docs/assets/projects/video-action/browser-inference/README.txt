Our Solution browser teaching application

This package contains the complete runnable browser application, its corresponding source, export recipes and the assets used by the approved demonstration.

To view locally, serve this directory with an HTTP server and open index.html in a modern browser. Additional optional models and MediaPipe components load from their original public sources. User-selected videos are read on the user's device.

Application source is distributed under AGPL-3.0 with the original Apache notices retained. Models and example videos keep their own terms and attribution in THIRD_PARTY_NOTICES.txt. The KTH example is restricted to non-commercial use. The included Pexels excerpts are input assets of this functioning annotated teaching application.

The package contains frozen pretrained-model conversions, not newly trained weights. Source and export details are provided under source/.
