## 模型与运行库

| 组件 | 来源及许可依据 |
|---|---|
| Ultralytics YOLO26s | 官方 `v8.4.0` 的预训练 `yolo26s.pt`，使用 `ultralytics==8.4.202` 转为 ONNX，输入为 960×960，opset 17，固定形状，未简化模型。没有进行训练或微调。转换产物按 AGPL-3.0 提供，上游源码、权重来源与许可链接列于下文。 |
| PyTorchVideo X3D-S | 来自 PyTorchVideo 官方模型库，转换为 ONNX 以供浏览器推理。发布依据是 PyTorchVideo 项目公布的 Apache-2.0 许可，并在复核的上游资料中未发现针对该检查点另列的排除条款。这是维护者对项目级许可范围的判断，上游未向本项目出具单独的权重授权。原许可文本随包保留。 |
| ONNX Runtime Web | Microsoft ONNX Runtime，MIT 许可。浏览器加载的包保留其上游声明。 |
| MediaPipe Tasks、LiteRT.js、Transformers.js | 从各上游公开软件包加载，保留其 Apache-2.0 许可和版权声明。Google 托管的 MediaPipe 模型由浏览器从官方地址读取，模型卡及来源说明由上游提供。 |
| 其他可选模型 | MoViNet、Qualcomm VideoMAE 和 Apple MobileCLIP 保留各模型发布者的条款。模型选项中的原名称和来源不变。 |

## 示例视频

KTH 挥手示例来自 Schuldt、Laptev、Caputo 的 KTH Action Database，使用 `person15_handwaving_d1` 前 7.8 秒，保留原 160×120 灰度分辨率并转为 H.264。上游允许非商业使用，本页面用于非营利教学和科研演示。引用为 Christian Schuldt、Ivan Laptev、Barbara Caputo，*Recognizing Human Actions: A Local SVM Approach*，ICPR 2004。[KTH 官方来源与使用说明](https://www.csc.kth.se/cvap/actions/)
