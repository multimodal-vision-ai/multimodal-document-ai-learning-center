# 论文索引：找到原文与官方代码

本页用于**定位论文原文**，不是替代[论文导读](../reading/README.md)。找到论文后，请回到导读页完成“问题—主张—证据—限制—下一步”。

## 优先使用的入口

### [arXiv](https://arxiv.org/)

适合查预印本、最新版本和作者提交历史。记录论文版本与访问日期，不要只保存 PDF 文件名。

### [AMiner / 智谱 AI（国内学术平台）](https://www.aminer.cn/)

适合检索 CVPR、ICCV、ECCV 等计算机视觉会议论文和研究者信息。找到目标论文后，再到论文原文、作者主页或官方代码仓库核对版本与实验信息。

### [ACL Anthology](https://aclanthology.org/)

适合查 ACL、EMNLP、NAACL 等自然语言处理与多模态研究论文，并获取稳定引用信息。

### [NeurIPS Proceedings](https://papers.nips.cc/)

适合查 NeurIPS 正式论文，尤其是模型方法、训练系统和 Datasets & Benchmarks 工作。

### [Hugging Face Papers](https://huggingface.co/papers)

适合发现近期论文及相关模型、代码线索；最终事实仍应回到论文原文、作者仓库与数据主页核对。

## 用研究问题搜索

不要只搜索模型名。把检索词组织成：

```text
任务 + 方法或约束 + 数据或评测

示例：document parsing reading order benchmark
示例：vision language model table structure evaluation
示例：multilingual document understanding low-resource
```

## 找到论文后先做四项核对

1. 标题、作者、年份和版本是否一致？
2. 代码链接是否来自作者或论文官方项目？
3. 数据与评测是否有独立的官方主页或说明？
4. 当前课程能否在一周内验证其中一个最小主张？

!!! tip "停止继续搜索的条件"
    当你已经找到一篇直接回答当前问题、原文可访问、代码或数据可核查的论文，就先完成一页论文卡。继续堆积候选论文通常不会让问题更清楚。
