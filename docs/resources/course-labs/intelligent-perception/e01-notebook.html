方式 B · 在 Kaggle 运行

登录 Kaggle，新建 Notebook，导入同一份 .ipynb。将本实验素材包建立为 Kaggle Dataset 并添加到右侧 Input；Notebook 会自动寻找其中的 images 目录。

下载 Kaggle 素材包打开 Kaggle

操作步骤

  1. 下载本页的标准 Notebook 和 MVAI_E01_Lab.zip。
  2. 在 Kaggle 创建 Dataset，上传并保留素材的 images/ 目录。
  3. 新建 Code Notebook，导入 E01_Image_Processing_V2.0.ipynb。
  4. 添加数据集，然后点击 Run All，修改实验参数后再次运行。

这是手动导入流程；目前尚未发布可直接运行的 Kaggle 公共 Notebook，因此不提供虚假的一键运行链接。
