## 五项探索

### 1 · 颜色空间与黄白车道线

**问题：** 为什么黄色标线和白色标线不能只用同一个颜色阈值？

将 RGB 转为 HSV，分别修改黄线的色调范围、白线的明度阈值，比较误检与漏检。

```python
hsv = cv2.cvtColor(image_bgr, cv2.COLOR_BGR2HSV)
yellow = cv2.inRange(hsv, (15, 70, 70), (40, 255, 255))
white = cv2.inRange(hsv, (0, 0, 175), (179, 85, 255))
```

[用浏览器探索颜色空间](interactive/index.html?lab=e01&exp=color)

### 2 · 不同阈值方法

比较全局阈值、Otsu 与自适应阈值。将亮路面与阴影图片互换，思考：一个固定阈值为什么无法适应所有场景？

### 3 · Gaussian / Median / Bilateral 滤波

固定同一张图片，修改滤波核大小与强度，分别观察边缘清晰度与噪声；同时区分原始噪声和人为加入的实验噪声。

### 4 · 腐蚀、膨胀、开运算、闭运算

在黄白标线掩膜上修改结构元素大小，比较小噪点、断裂标线和真实边缘如何变化。

### 5 · 透视变换与近似鸟瞰图

修改道路梯形的四个控制点，观察近大远小的视觉效果如何改变；思考为什么未经相机标定不能得到真实的米制车道位置。
