# E03 · Advanced Lane Finding V2.0

**基于传统计算机视觉的道路车道线检测与分析**

本实验以一份完整 Notebook 组织五个连续实验：相机标定、颜色与梯度阈值、透视变换、车道像素搜索与二次曲线拟合、曲率与车辆偏移及连续视频处理。

## 三段真实视频

| 场景 | 素材 | 教学定位 |
|---|---|---|
| 直道 | `solidWhiteRight.mp4` | 观察基础车道线提取和检测流程 |
| 普通弯道 | `project_video.mp4` | 观察透视变换、曲线拟合与连续检测 |
| 复杂弯道 | `harder_challenge_video.mp4` | 保留边界漂移、误选等失败现象，作为课后探索 |

学生默认处理每段约 8 秒短片；Notebook 可切换完整视频处理。CPU 即可运行，不要求 GPU。

## 算法与教学边界

- 采用 OpenCV 传统视觉流程：相机标定、畸变校正、HLS/Sobel 阈值、透视变换、滑动窗口、二次多项式拟合。
- 复杂道路的失败现象是教学材料的一部分，不以人工修饰结果掩盖。
- 视频没有人工车道线 Ground Truth；内部几何检查通过率不是识别准确率。
- 曲率与车辆偏移采用固定尺度假设，不代表道路实测值。
- 本实验用于计算机视觉教学，不用于自动驾驶安全决策。

## 课后思考探索

请学生从复杂弯道视频中选择一个失败片段，记录时间点，结合原图、二值图、俯视图和拟合曲线，分析阴影、候选像素污染、透视参数和二次曲线模型的影响，并提出一种可验证的改进思路。
