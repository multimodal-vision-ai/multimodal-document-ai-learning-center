# E03 · 复杂道路车道检测

[E03 独立综合教学页面](e03-notebook.html){ .md-button .md-button--primary }

本实验保留 V1.0 作为传统算法 Baseline，并新增 V1.1 改进方案。使用真实直道、普通弯道和复杂连续弯道视频，研究透视变换、标线提取、曲线拟合、动态搜索和时序跟踪。

## 两个版本

- **V1.0 Baseline：** 原始 HLS/Sobel 候选、滑动窗口、二次曲线拟合和 EMA。
- **V1.1 Improved：** 自适应标线候选、RANSAC 二次/三次曲线、分段主像素簇与自然三次样条、基于历史曲线的动态搜索、Kalman 跟踪与有限失效恢复。
