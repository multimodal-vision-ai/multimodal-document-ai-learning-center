## 五项探索

### 1 · Canny：边缘并非语义

**问题：** 阈值降低、检测到更多边缘，就一定意味着车道线检测更好吗？

```python
gray = cv2.cvtColor(image_bgr, cv2.COLOR_BGR2GRAY)
blurred = cv2.GaussianBlur(gray, (5, 5), 1.2)
edges = cv2.Canny(blurred, 50, 150)
```

### 2 · ROI：为什么要缩小关注区域？

修改梯形顶边高度，比较远处车道线保留与路外干扰；换一张急弯图片观察固定 ROI 的失效现象。

### 3 · Hough：边缘如何变成候选直线？

调整投票阈值、最小线长及间隙长度，观察候选线段数量和位置。

```python
lines = cv2.HoughLinesP(
    masked_edges, 1, np.pi / 180,
    threshold=25, minLineLength=35, maxLineGap=70
)
```

### 4 · 左右候选线筛选

根据线段斜率和与画面底部的交点筛选候选线段，认识“几何上合理”和“真实车道线”之间的区别。

### 5 · 固定参数能否跨场景使用？

用同一组参数处理九张图片，比较直道、弯道、车辆干扰、树影与强光。分析为什么某些场景的算法会失效。

## 学习延伸

- 在不同图片上只修改一个参数并记录结果。
- 不把 Hough 候选线条数当作准确率，也不把启发式左右拟合当作人工 Ground Truth。
