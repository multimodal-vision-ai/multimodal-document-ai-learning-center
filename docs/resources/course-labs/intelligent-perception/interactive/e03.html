MVAI Learning Center / E03 浏览器交互实验
本模块沿用 E01、E02 的浏览器交互方式。选择道路场景、调整参数并观察中间结果。算法在学生浏览器本地运行，不需要 Python 或 GPU。浏览器实现用于理解原理，不承诺与 OpenCV 逐像素一致。

实验 01 · 相机标定与畸变校正

先观察真实棋盘格角点检测结果，再通过径向畸变模拟滑块观察镜头畸变对道路图像几何形状的影响。真实相机内参与畸变系数仍由 Notebook 中的 Python/OpenCV 使用 18 张有效标定视图计算。

这是用于理解畸变方向和强度的教学模拟值，不是本相机实测标定参数。
调整 k1，观察图像边缘与中心区域的几何变化。
思考：为什么不能只用一张棋盘格图片？相机位置、角度和棋盘格覆盖范围会怎样影响内参估计？

实验 02 · HLS 颜色与 Sobel 梯度阈值

滑动阈值，实时观察浏览器端生成的候选像素。颜色阈值与梯度阈值共同决定哪些像素进入后续车道线搜索。

调整阈值后，候选像素数量和二值图将同步更新。
浏览器版以 HSL 亮度 / 饱和度与 Sobel X 梯度构造教学候选图，算法实现与 Python/OpenCV 版存在差异。请观察阴影、天空、车辆边缘是否也被选中。

实验 03 · 透视变换与道路俯视图

拖动参数，观察原图中的四边形源区域如何变化。右侧俯视图由浏览器端根据当前四边形源区域实时计算生成；调整顶部位置、顶部宽度和底部宽度，观察透视映射结果同步变化。

源点过高或过低、顶部过宽或过窄，都会改变实时俯视图中的道路几何形状。请比较不同场景下同一组透视参数的适用性。

实验 04 · 滑动窗口与车道线像素搜索

改变窗口数量与搜索宽度，观察窗口如何沿候选像素向上移动。窗口中心由当前二值图下半部分的左右像素直方图初始化，并根据窗口内像素重新定位。

调整窗口层数和半宽，观察搜索区域、选中像素及拟合曲线变化。
窗口可以跟随高密度像素移动，但也可能被护栏、阴影边缘或路面接缝吸引。复杂弯道中的漂移现象保留为课后探索案例。

实验 05 · 连续视频观察
