实验 E03-01 · 相机标定与图像畸变校正

使用 20 张棋盘格图片，检测 9×6 内角点并计算相机内参与畸变系数。Notebook 会逐张报告检测状态。

探索任务（3项）

  • 改变参与标定的图片数量，比较重投影 RMS。
  • 比较传统角点检测与 SB 角点检测。
  • 改变 alpha，观察有效视野和图像边缘。

实验 E03-02 · 颜色空间与梯度阈值提取

将道路像素转换到 HLS 颜色空间，并计算 Sobel X 梯度。通过颜色和梯度阈值融合，形成车道线候选二值图。

探索任务（4项）

  • 调整黄色车道线 HLS 阈值。
  • 调整 Sobel X 梯度阈值。
  • 比较 AND / OR 融合策略。
  • 使用同一组阈值观察三种光照与道路场景。

实验 E03-03 · 透视变换与道路俯视图构建

利用源点和目标点计算单应性矩阵，将驾驶视角转换为近似俯视视角。

探索任务（3项）

  • 改变源点顶部位置。
  • 改变目标区域宽度。
  • 比较同一组透视坐标在三段视频中的表现。

实验 E03-04 · 车道线像素搜索与二次曲线拟合

先对俯视二值图进行直方图统计，再通过滑动窗口逐层搜索左右车道线像素，最后使用二次多项式拟合。

拟合模型：x(y) = Ay² + By + C

探索任务（4项）

  • 调整滑动窗口数量。
  • 调整搜索窗口宽度。
  • 调整每个窗口的最少像素数。
  • 比较全图滑动窗口搜索与上一帧曲线附近搜索。

实验 E03-05 · 道路曲率、车辆偏移与连续视频检测

将前四个实验连接为完整处理流程，计算近似道路曲率和车辆横向偏移，并观察连续视频中的逐帧检测与简单 EMA 平滑。

探索任务（4项）

  • 改变车道宽度假设，观察米制结果。
  • 改变二次曲线系数，观察曲率变化。
  • 比较不同 EMA 参数的时序平滑效果。
  • 切换三段视频，比较检测表现和失败案例。

05 · 三段真实道路视频 · 原始画面与检测结果

视频由 Notebook 中的 OpenCV 算法实际处理生成。每个场景提供原始画面与检测结果同步对比，以及单独的处理结果视频。

当前：直道场景；每段默认展示约 8 秒。Notebook 可切换完整视频处理。

视频没有人工车道线 Ground Truth。几何检查通过率不等于识别准确率。请同时观察误检、漏检和曲线不合理的情况。

算法局限与课后思考探索

  • 固定颜色阈值可能受到阴影、强光和路面颜色影响。
  • 透视变换参数与摄像机视角和安装位置有关。
  • 滑动窗口可能把护栏、道路接缝和其他标线当成车道线。
  • 二次曲线不能表达所有道路几何形状。
  • 连续视频需要考虑时间信息，但历史结果也可能造成错误延续。
课后思考：复杂道路为什么检测失败？ harder_challenge 场景中的车道边界漂移和误选现象是本课程有意保留的真实失败案例。请学生选取失败时间点，结合原图、二值图、俯视图和拟合曲线，分析阴影干扰、候选像素污染、透视参数和二次曲线模型，并提出一种可验证的改进思路。
曲率与车辆偏移采用车道宽度 3.7 m、纵向观察范围 30 m 的教学尺度假设，不是道路实测值。本实验仅用于理解经典计算机视觉方法，不用于自动驾驶安全决策。

方式 B · Kaggle Notebook

上传完整实验包作为 Kaggle Dataset，导入同一份 Notebook 并添加数据集。默认处理三段视频的短片段；需要完整处理时再修改配置。

下载完整素材包 ZIP
  1. 在 Kaggle 创建 Dataset 并上传实验包。
  2. 新建 Notebook，导入 E03 标准 ipynb。
  3. 添加数据集后运行全部单元格。
  4. 观察三段视频结果，完成探索任务。
运行说明：CPU 即可运行，不要求 GPU。浏览器交互版用于直观理解算法原理，与 Python/OpenCV 结果不保证逐像素一致。
