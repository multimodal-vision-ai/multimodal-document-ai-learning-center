## 把一次收藏变成一次行动

资源的价值不在于“看过多少”，而在于它是否帮助你提出问题、动手验证并形成自己的判断。

| 可用时间 | 建议行动 | 最小产出 |
| --- | --- | --- |
| 20 分钟 | 阅读一个官方 quickstart 或 model card | 3 个已理解要点与 1 个疑问 |
| 2 小时 | 跑通最小示例，只改变一个输入或参数 | 前后结果与原因解释 |
| 半天 | 用两个官方方案处理同一个小任务 | 一份有证据的选择说明 |
| 1 周 | 围绕一个问题整理小型 Benchmark 或学习笔记 | 可复用、可核查的公开作品 |

## 建立自己的自学循环

```text
提出一个具体问题
        ↓
找到最接近问题的官方入口
        ↓
阅读当前版本的 quickstart / model card / dataset card
        ↓
运行最小示例，只改变一个变量
        ↓
保存来源、配置、结果与限制，并解释观察
        ↓
形成下一个更好的问题
```

!!! tip "每次离开资源页时"
    至少带走一项可执行内容：一个待验证的问题、一次小实验，或一条能够支持判断的证据链接。

## 资源选择标准

### Official First

模型和框架优先引用维护方官网、官方 GitHub、官方文档或官方 Hugging Face 组织；论文优先引用出版页或 arXiv 原文；数据优先引用数据集主页和 dataset card。

### Task Fit

资源必须回答当前任务中的具体问题。一个链接如果既没有学习目标，也没有使用时机，即使内容优秀，也不应堆到课程主线中。

### Maintainable

站内只保留必要的选择理由、学习顺序和验收要求。容易随版本变化的安装命令、API 参数和模型列表交给官方页面维护。

### Responsible Use

使用模型、数据和平台前检查 license、隐私、访问权限和地域/账户限制。不要把“可以下载”理解为“可以任意公开或商用”。

## 链接失效怎么办

先在同一官方域名或官方组织中寻找新地址，再提交 issue/PR 更新链接。不要用来源不明的转载页替换官方材料，也不要为了让自动检查通过而忽略所有 401/403 响应。
