实时文档结构化解析-DocTags

ⓘ
本平台面向文档结构化解析与多模型能力对比：对同一文档选择兼容模型，查看 DocTags、版面定位及结构化渲染结果，并比较不同模型的解析效果。 当前内置 IBM Granite Docling 258M 公开基线、OvisOCR3 0.8B、PaddleOCR-VL-1.6 0.9B，以及 MVAI-DocTags-DJX-0.8B-v1.0 · 自研和 MVAI-DocTags-WC-2B-v1.0 · 自研模型。OvisOCR3 与 PaddleOCR-VL-1.6 保留各自原生 Structured JSON / parsing_res_list 输出，不转换成 DocTags；均使用浏览器本机 WebGPU。 支持的模型在访问者浏览器中使用 WebGPU 推理，当前仍属实验功能。模型兼容性和解析准确率须按实际结果核验。
技术预览 · 首次加载 DJX-0.8B 约下载 2.52 GB，WC-2B 约下载 6.2 GB；OvisOCR3 与 PaddleOCR-VL-1.6 还需下载各自的模型资源。
ⓘ
建议使用支持 WebGPU 的桌面浏览器和稳定网络。模型下载后可复用浏览器缓存，但显存实例仍需初始化。请勿上传含敏感个人信息或未经授权的文档；模型兼容性与解析准确率尚待系统验收。
