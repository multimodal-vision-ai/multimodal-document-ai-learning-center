    One Fact, Many Places¶

    聚焦长文档 RAG 中冗余证据的评测问题，尤其是同一事实可能在多个位置重复出现时，如何评估系统对这些证据的处理能力。

    入选理由：已存档的 ChatGPT 每日预警将其列为值得关注的研究进展；它指向长文档检索中一个可明确构造测试条件、比较不同方法的评测问题。

    研究切入点：可进一步设计不同证据重复率、跨章节分布和检索预算的对照实验，分析冗余证据对召回、答案忠实性与推理成本的影响；具体方法和实验结论应以论文原文为准。

    参数规模：未报告 · GPU：未核实

    科研筛选结果报告时间：2026-10-20

    RPD + SARA¶

    结构感知的统一文档解析方法，目标是更好保留文档布局和结构信息。已存档周报报告了 layout F1 为 0.9189、对比 LoRA baseline 的 0.7004；该数值应结合原论文的实验设置核验。

    入选理由：原周报列为 A 优先级；模型权重和数据被记录为开放，且提供了 GitHub 与 Hugging Face 入口，适合作为文档解析的复现基线。

    研究切入点：在跨版式、长文档、表格混排和扫描质量变化条件下复现布局指标；比较量化推理、LoRA 微调与结构约束对精度和显存的影响。

    参数规模：2B · GPU：T4 量化推理可行；LoRA 约需 24GB；全量训练至少约 40GB（按已存档周报记录，需实测复核） · 权重：已标记开放 · 数据：已标记开放

    科研筛选结果报告时间：2026-10-19
    论文 · GitHub · Hugging Face

    semCER¶

    面向 OCR 的语义严重度加权评测思路，试图区分对含义影响不同的识别错误，而不只把所有字符编辑视为等价。

    入选理由：已存档周报记录了 T4 16GB 环境测试，并报告 FP32 约 46 edits/s；完整蒸馏流程尚未确认，适合开展可复现实验和评测方法研究。

    研究切入点：检验语义严重度指标与下游信息抽取、文档问答质量之间的相关性，并在多语言、表格和票据 OCR 场景中进行对照。

    参数规模：0.8B · GPU：已存档周报记录 T4 16GB 可运行；约 46 edits/s 为 FP32 报告值，需按原设置复核 · 权重：已标记开放

    科研筛选结果报告时间：2026-10-19

    从这里开始¶

    如果你是第一次进入实验室或首次系统学习 Multimodal Document AI，依次完成三个动作：

    1. 打开入门课程，理解 12 周要形成的能力与作品；
    2. 查看每周计划，从 Week 1 的最小任务开始；

    课程以中文为主，关键术语保留英文；每周建议投入约 24 小时，由学生自主安排主线、探索与复盘，并明确回答：

    从当前主线走向未来¶

    学习方向 现在可以做什么 下一步可以追问什么
    文档理解 / Document Understanding OCR、版面、表格、文档问答与结构化解析 模型能否理解更长、更复杂、更真实的文档？
    视觉语言模型 / VLM 图像输入、Prompt、失败分析与小规模后训练 模型如何连接视觉证据、语言与推理？
    视频理解 / Video Understanding 复用 VLM、评测和实验管理能力 如何理解时间、事件、动作和长视频上下文？
    多模态智能应用 构建可复现 pipeline 与可信 Benchmark 如何把感知、推理和智能体连接到真实场景？

    这里不是终点

    文档理解是当前课程的训练场。你在这里形成的数据、模型、评测和研究表达能力，可以继续迁移到图像、视频、机器人与行业智能问题。

    12 周能力路线¶

    阶段 周次 核心成果
    Reproducible Builder Week 1–3 Git/Python 环境、模型调用、AI 辅助编程与验证
    Document AI Explorer Week 4–7 VLM、文档解析、Dataset 与 Benchmark
    Model Experimenter Week 8–10 LoRA/PEFT、W&B runs、统一评测与消融
    Research Communicator Week 11–12 论文复现、Capstone、Model Card 与答辩

    没有独立 GPU？

    仍可开始。Week 1–7 可在普通电脑或小规模云端环境完成；Week 8–10 可使用 Kaggle/Colab、小模型和小数据。自主检查关注方法与证据，不比较模型规模。

    你最终会完成什么¶

    课程结束时，你将拥有一个可以由他人检查和复现的小型研究项目，其中包含：

    • 可重建的环境与明确运行入口；
    • 授权清晰的数据与固定 test set；
    • baseline、改进方法和自动评测；
    • AI-assisted coding 使用与人工验证记录；
    • LoRA/PEFT 微调配置；
    • 至少两个可比较的 W&B runs 与 Report；
    • 错误分析、限制、Model Card 和成果展示。

    学习原则¶

    Official First¶

    技术细节优先链接模型、框架和数据集的官方文档。课程页面负责说明学习路线、任务和自主检查，不重复维护容易过时的长篇 API 教程。

    Evidence First¶

    “运行成功”只是起点。结论必须能够追溯到输入、版本、配置、原始输出、指标与失败案例。

    Responsible AI¶

    不提交密钥、隐私数据或未授权材料；披露 AI 的参与范围；对 AI 生成代码与模型输出进行人工验证。

    准备好了吗？从 Week 1 建立你的第一份可复现实验证据。
