# 🧭 MV-AI Lab AI Research Learning Roadmap

## From AI User to AI Researcher

本路线面向希望进入多模态人工智能研究与实践的学生。

学习过程遵循：

```
Learn → Build → Experiment → Benchmark → Research
```

---

# Stage 1 · AI Foundation

## Goal

建立人工智能研究与工程基础。

## Topics

- Python Programming
- Git & GitHub
- Deep Learning Basics
- PyTorch
- Transformers

## Outcome

能够独立运行和修改 AI 模型代码。

---

# Stage 2 · Multimodal Foundation Models

## Goal

理解现代多模态大模型。

## Topics

- Vision Language Models
- Multimodal Transformers
- Prompt Engineering
- Model Inference

## Models

- Qwen-VL
- LLaVA
- DeepSeek-VL

## Outcome

能够使用开源多模态模型完成任务。

---

# Stage 3 · Document Intelligence

## Goal

探索 AI 对复杂文档的理解能力。

## Topics

- OCR
- Document Parsing
- Layout Understanding
- Document Question Answering

## Benchmarks

- OmniDocBench
- DocLayNet
- PubTabNet

## Outcome

完成 Document AI 实验项目。

---

# Stage 4 · Model Adaptation

## Goal

掌握模型优化与训练方法。

## Topics

- LoRA
- QLoRA
- SFT
- Preference Optimization
- Evaluation

## Tools

- Hugging Face
- SWIFT
- Weights & Biases

## Outcome

能够完成模型微调实验。

---

# Stage 5 · Research Project

## Goal

从实验走向科研创新。

## Activities

- Read Papers
- Reproduce Results
- Design Experiments
- Build Benchmarks
- Write Papers

## Final Outcome

形成个人 AI Research Project。

---

# 🎓 Training Philosophy

优秀 AI 人才培养不是学习更多工具，而是建立：

- 科学问题意识
- 工程实现能力
- 实验验证能力
- 开源协作能力
